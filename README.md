# Library Management System

A console-based Java project demonstrating **Core Java**, **OOP principles**, and **hand-built data structures**.

# Features
- Add/search books and register Student/Faculty members
- Issue, return, and reserve books (with a waiting queue)
- Automatic late-return fines (₹5/day, 14-day loan period)
- Transaction history (most-recent-first)
- Weekly issue chart & fine chart — printed as ASCII in the console, and as a real graph window (Swing)
- Export the book catalog to a text report

# Tech / Concepts Used
- **OOP:** encapsulation, inheritance, polymorphism, abstraction (`Person → Member → Student/Faculty`)
- **Custom data structures:** `CustomLinkedList`, `CustomQueue`, `CustomStack` (no `java.util` equivalents)
- **Core Java:** custom checked exceptions, enums, generics, `Comparable`, `java.time`, file I/O, Swing
